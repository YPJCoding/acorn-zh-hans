## 二、 术语基线（强制对齐）

| 英文 | 中文 | 注释与准则 |
| --- | --- | --- |
| **Canvas** | 画布 | 严格与图像（Image）和图层（Layer）区分 |
| **Selection** | 选区 | 名词形态为“选区”，动词 Select 为“选择” |
| **Layer** | 图层 | Group 为“图层组”或“组” |
| **Layer Mask** | 图层蒙版 | 统一使用“蒙版”，不用“遮罩”混写 |
| **Color Profile** | 颜色描述文件 | ICC、Display P3、sRGB 等标准名称保留 |
| **Opacity** | 不透明度 | 与 transparency（透明度）严格区分 |
| **Blend Mode** | 混合模式 | 遵照 Photoshop / macOS HIG 标准模式命名（正片叠底、滤色、叠加等） |
| **Resample** | 重采样 | 与仅改变 DPI 的尺寸调整区分 |
| **Rasterize** | 栅格化 | 与“合并”或“拼合”区分 |
| **Flatten Image** | 拼合图像 | 与“合并图层”区分 |
| **Preset** | 预设 | 技术或用户自定义预设名不盲译 |
| **Crop** | 裁剪 | Trim 统一为“修边/修剪边缘” |
| **Export** | 导出 | 与保存原生文档区分 |
| **Inspector** | 检查器 | 与具体工具选项面板区分 |

## 三、 分模块工作与验收标准

1. **设置 / 新建 / 打开 / 保存**：偏好设置各面板、新建图像参数、保存与覆盖警告。
2. **工具 / 选区 / 图层**：画笔与设计器、图层右键菜单、蒙版（应用/分离/停用）、图层组、锁定状态、布尔运算。
3. **文字 / 形状 / 色彩**：字体族、路径文字、环形文字、对齐与分布、颜色管理与不同位深（8/16/32 bpc）。
4. **滤镜 / RAW / 导出**：滤镜分类与参数、LUT 查找表、RAW 面板、WebP/PNG/JPEG 专属导出设置。
5. **自动化 / 错误提示 / 帮助入口**：JavaScript 脚本、权限不足提示（如屏幕录制权限）、保存失败与缺失资源弹窗。

## 四、 新版本升级与增量流程 (SOP)

当官方发布新版本（如 Acorn 8.7.x）时：
1. 运行 `python3 core/acorn_tool.py diff --app /Applications/Acorn.app`，动态提取新版增量；
2. AI Agent 结合本术语基线及内置德/法/西对照（Refs）自动补齐新增条目；
3. 严格校验 `%@`、`%d`、`\n` 占位符后合并入库；
4. 运行 `python3 core/acorn_tool.py apply` 原生重签生效；
5. 执行 `python3 -m unittest discover -s tests -v` 验证沙箱安全性与可逆性。
